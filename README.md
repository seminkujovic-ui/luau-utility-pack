# Luau Utility Pack

A lightweight collection of reusable Luau utilities for Roblox developers.

Simple, dependency-free modules for common tasks without requiring a large framework.

## Features

### Cooldown
- Create cooldowns for players, abilities and interactions
- Check if a cooldown is ready
- Get remaining cooldown time
- Reset cooldowns

### Timer
- Start, pause and resume timers
- Check remaining time
- Reset timers
- Check if a timer has finished

### Random
- Pick random items
- Shuffle arrays
- Generate random numbers
- Probability checks

### TableUtil
- Count entries
- Find values
- Reverse and copy arrays
- Filter and map values
- Clear tables

## Installation

Copy the modules you need from the `src` folder into your Roblox project.

No external dependencies are required.
